# 백그라운드 녹화 (BgRecorder)

앱을 닫거나 홈 화면으로 나가도, 화면이 꺼져도 카메라 영상을 계속 녹화하는 안드로이드 앱입니다.
Kotlin + CameraX + 포그라운드 서비스 방식이며, 녹화 중에는 상단 알림이 항상 표시됩니다.

## 열고 실행하는 순서

1. **Android Studio** 설치 (최신 안정 버전)
2. `File → Open` 에서 이 `BgRecorder` 폴더 선택
3. 처음 열면 Gradle 동기화가 자동으로 진행됩니다 (인터넷 필요, 몇 분 걸림)
4. 휴대폰에서 **개발자 옵션 → USB 디버깅** 켜고 PC에 연결
5. 상단의 ▶ Run 버튼으로 설치 (Android 11 이상 기기)
6. APK 파일만 필요하면 `Build → Build Bundle(s) / APK(s) → Build APK(s)`

## PC 없이 휴대폰만으로 설치하기 (GitHub 자동 빌드)

1. 휴대폰 브라우저로 github.com 에 로그인 → 새 저장소(New repository) 만들기
2. `Add file → Upload files` 로 `BgRecorder.zip` **파일 그대로** 올리고 Commit
3. `Add file → Create new file` 에서 파일 이름을 `.github/workflows/build.yml` 로 입력하고
   이 프로젝트의 `.github/workflows/build.yml` 내용을 붙여넣은 뒤 Commit
4. 저장소의 **Actions** 탭 → `Build APK` 실행이 끝날 때까지 대기 (3~6분, 초록 체크 표시)
5. 실행 결과 화면 맨 아래 **Artifacts → BgRecorder-apk** 를 눌러 다운로드 (zip 파일)
6. 휴대폰 '내 파일'에서 zip 압축 해제 → `app-debug.apk` 를 눌러 설치
   ('출처를 알 수 없는 앱 설치' 허용 필요)

## 사용법

1. 앱을 열고 후면/전면 카메라, 소리 녹음 여부 선택
2. **녹화 시작** → 권한(카메라, 마이크, 알림) 허용
3. 홈 버튼을 눌러 다른 앱을 써도 녹화가 계속됨
4. 끝낼 때는 상단 알림의 **중지** 버튼 또는 앱 안의 **녹화 중지**
5. 영상은 갤러리의 `Movies/BgRecorder` 폴더에 mp4로 저장

## 바로가기로 한 번에 녹화하기

화면을 거치지 않고 아이콘을 누르는 즉시 녹화가 시작되고, 다시 누르면 중지됩니다.
마지막으로 고른 카메라·소리 설정이 그대로 사용됩니다.

- **앱 아이콘 길게 누르기** → '빠른 녹화' 메뉴 선택 (메뉴 아이콘을 끌어서 홈 화면에 놓을 수도 있음)
- **홈 화면에 전용 아이콘 만들기**: 앱 안의 '홈 화면에 바로가기 추가' 버튼 → 확인 팝업에서 추가
- 권한은 앱을 한 번 열어 허용해 두는 것을 권장합니다 (바로가기에서도 처음엔 권한 팝업이 뜹니다)
- 화면이 켜진 상태에서 눌러야 시작됩니다. 시작한 뒤에는 화면을 꺼도 계속 녹화됩니다.

## 잘 안 될 때

- **삼성/샤오미 등에서 몇 분 뒤 꺼짐**: 앱 안의 '배터리 최적화 제외 설정 열기' 버튼 → 이 앱을 '제한 없음'으로
- **녹화가 시작 안 됨**: 앱 화면이 보이는 상태에서 시작해야 합니다 (Android 12+ 제한)
- **알림이 안 보임**: 설정에서 이 앱의 알림 권한 허용
- 다른 앱이 카메라를 쓰는 중이면 녹화가 중단될 수 있습니다

## 파일 구조

| 파일 | 역할 |
|---|---|
| `MainActivity.kt` | 권한 요청, 시작/중지 버튼, 상태 표시 |
| `RecordingService.kt` | 포그라운드 서비스, CameraX 녹화, 알림, WakeLock |
| `QuickRecordActivity.kt` | 바로가기로 열리는 투명 화면 (녹화 시작/중지 토글 후 즉시 닫힘) |
| `Prefs.kt` | 마지막에 고른 카메라·소리 설정 저장 |
| `res/xml/shortcuts.xml` | 앱 아이콘 길게 누르기 메뉴 정의 |
| `AndroidManifest.xml` | 카메라/마이크 포그라운드 서비스 타입과 권한 선언 |

## 알아둘 점

- Android 11+ 는 카메라/마이크 사용 중 상단에 초록 점이 뜨며, 이건 막을 수 없습니다.
- 본인 기기·본인 공간(매장 CCTV, 블랙박스 등) 용도로 사용하세요. 타인을 몰래 촬영하는 용도는 법적으로 문제가 됩니다.
- iOS는 OS 정책상 백그라운드 카메라 녹화가 불가능해 지원하지 않습니다.
